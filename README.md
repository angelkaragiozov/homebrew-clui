# Homebrew Tap for CLUI

This repository is a custom Homebrew tap for installing the **CLUI** desktop application on macOS.

## Installation

To tap this repository and install CLUI, run the following commands in your terminal:

```bash
# Tap the repository
brew tap angelkaragiozov/clui

# Install the application as a Cask
brew install --cask clui
```

## Updating

To update CLUI when a new version is released:

```bash
brew update
brew upgrade clui
```

## Uninstalling

To remove the application:

```bash
brew uninstall clui
```
